3. SHAP 피처 중요도 (CSV 1개 + PNG 8개)

경로: export/shap/

파일 수: CSV 1개 + PNG 8개

생성 방법 (요약): SHAP 알고리즘으로 LightGBM 모델의 피처별 기여도를 산출.

생성 방법 (상세): 학습 완료된 LightGBM 모델에 SHAP TreeExplainer를 적용하여 각 입력 피처(부분실측 비율, 이동평균, 기상 변수 등)가 최종 예측에 얼마나 기여했는지를 정량화한 결과입니다. 구체적 과정: (1) 테스트 데이터에 대해 SHAP 값을 산출합니다. SHAP 값은 게임이론의 Shapley value에 기반한 모델 해석 지표로, 각 피처가 예측값을 얼마나 높이거나 낮추는지를 나타냅니다. (2) 전체 피처의 평균 절대 SHAP 값으로 글로벌 중요도 순위를 매깁니다. (3) 상위 5개 피처에 대해 dependence plot을 시각화합니다. (4) 개별 예측 사례에 대해 waterfall plot으로 예측 분해 과정을 시각화합니다.

원본 미포함 피처 이름과 SHAP 기여도 수치만 포함.

5. 기상 민감도 분석 (CSV 4개)

경로: export/sensitivity/

파일 수: 4개

생성 방법 (요약): 기온·강수·일사 피처에 인위적 편향을 추가하여 모델 예측의 기상 오차 민감도를 측정.

생성 방법 (상세): 실제 운영 시 기상 예보의 불확실성이 예측 성능에 미치는 영향을 정량화하는 분석입니다. 구체적 과정: (1) 학습된 LightGBM 모델의 테스트 데이터에서 기상 관련 피처(CDH/HDH, 기온, 강수량, 일사량)를 식별합니다. (2) 기온 민감도: 기온 피처에 -5, -3, -2, -1, +1, +2, +3, +5°C의 편향을 일괄 적용합니다. 기상청 중기예보 API의 기온 예보 상하한 범위(±2°C)를 근거로 설정. (3) 강수 민감도: 강수량/강수시간에 ×0.55, ×0.80, ×1.20, ×1.45 스케일을 적용합니다. 기상청 공식 강수예보 CSI 0.45 기반. (4) 일사 민감도: 일사량에 ×0.5, ×0.7, ×1.3, ×1.5 스케일을 적용합니다. (5) 각 조건에서 MAPE, MAE, RMSE, CVRMSE + 월별(m1~m12) MAPE를 산출합니다. 기상 데이터 자체는 기상청 ASOS 공공 데이터입니다.

9. Sliding 평가 — 기본 모델 (CSV 1개 + PNG 2개)

경로: export/sliding/

파일 수: CSV 1개 + PNG 2개

생성 방법 (요약): 검침일 기준 Sliding Window 평가. 예측값과 월간 집계 사용량의 오차를 기록.

생성 방법 (상세): 모델의 실제 운영 성능을 검증하기 위한 Sliding Window 평가의 상세 결과입니다. 구체적 과정: (1) 한전의 검침일 주기(1일, 15일)에 맞춰, 각 검침일로부터 +10일(10일 관측 후 잔여 ~20일 예측) 및 +20일(20일 관측 후 잔여 ~10일 예측) 시점에서 해당 월의 총 사용량을 예측합니다. (2) 예측에는 관측 기간의 실측 부분사용량(partial_kwh)과 고객 이력, 기상 변수 등을 입력으로 사용합니다. (3) 예측값(pred_monthly_kwh)과 해당 월의 실제 총 사용량(full_month_kwh)의 차이를 오차로 기록합니다. 이 파일로 반출 후 사용량 규모별, 계약종별 분리 분석이 가능합니다.
원본 데이터 소명: full_month_kwh는 원본 LP 15분 계량값의 월간 합계로, 집계된 파생값입니다. 원본 15분 시계열을 복원하는 것은 불가능합니다. partial_kwh도 기간별 합산 집계값입니다. pred_monthly_kwh는 모델이 산출한 예측값입니다.
