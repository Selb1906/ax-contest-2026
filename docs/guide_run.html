분석 실행 가이드

전기요금 과다발생 사전 예측모델 -- 안심구역 분석 절차

1. 환경 검증

1 패키지가 모두 설치되었는지 확인 
python -m scripts.verify_env

모든 항목에 통과 표시가 나오면 다음으로. 실패 항목이 있으면 직원에게 해당 패키지 설치 요청.

2. LP 데이터 찾기

2 데이터 경로를 모를 때 자동 탐색 
python -m scripts.inspect_lp --scan
python -m scripts.inspect_lp --scan --root D:/

후보 목록이 나오면 해당 경로로 구조 탐색:

python -m scripts.inspect_lp --path /찾은/경로/

이 명령은 configs/source_dsz.yaml을 자동 생성합니다. 컬럼 매핑을 확인하고 필요시 수정.

3. 전체 파이프라인 실행

3 메인 분석 (학습 + 평가 + SHAP + Ablation 등) 
python -m scripts.run_full_analysis --source configs/source_dsz.yaml

자동으로 실행되는 단계:

Step내용산출물
1데이터 로딩-
1.5전처리 (결측/이상값)preprocess_log/
2BTM(자가발전) 탐지btm_results/
3프로파일러profile_stats/
4베이스라인 5종 평가eval_results/baselines.*
4.5데이터 분할 + 누수 체크-
5LightGBM 학습weights/, eval_results/metrics.*
5.5Sliding 상세 평가sliding_results/
6SHAP 피처 중요도explain_results/
7~8기상 최적화weather_opt/
10~11Ablation (BTM/기상/피처)ablation_results/
11.5잔차 보정residual_correction/
중단 후 재개: --resume 플래그를 추가하면 체크포인트에서 이어서 실행
시간 절약: --skip-shap, --skip-profile 옵션으로 선택적 스킵 가능

4. 대시보드 생성

4 대시보드용 데이터 + HTML 생성 
python -m scripts.prepare_ui_data --source configs/source_dsz.yaml --meter-day 1
python -m scripts.generate_dashboard

브라우저에서 dashboard.html을 열면 분석 결과를 탭별로 확인할 수 있습니다.

5. 논문용 이미지

5 10종 시각화 자동 생성 
python -m scripts.generate_figures

결과: figures/ 디렉토리에 300dpi PNG

6. 반출 파일 수집

6 반출 안전 파일을 export/ 한 폴더에 모음 
python -m scripts.export_summary --dashboard

export/ 폴더만 반출 신청하면 됩니다.

반출 불가 파일: customer_id가 포함된 파일 (data/ui/, checkpoints/lgbm_preds.*, btm_flags.*, sliding_raw.*)은 반출할 수 없습니다. export/에는 집계 데이터만 포함됩니다.

한 줄 요약 (전체 순서)

python -m scripts.verify_env
python -m scripts.inspect_lp --scan
python -m scripts.inspect_lp --path /data/lp/
python -m scripts.run_full_analysis --source configs/source_dsz.yaml
python -m scripts.prepare_ui_data --source configs/source_dsz.yaml
python -m scripts.generate_dashboard
python -m scripts.generate_figures
python -m scripts.export_summary --dashboard
