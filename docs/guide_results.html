1. 모델 성능 비교

export/perf_모델_비교.csv

주요 지표

지표의미좋은 값해석
MAE (kWh)평균 절대 오차낮을수록예측이 평균적으로 얼마나 빗나가는지 (kWh 단위)
RMSE (kWh)평균 제곱근 오차낮을수록큰 오차에 더 민감 (이상치 영향 반영)
CVRMSE (%)변동계수 RMSE낮을수록RMSE를 평균 사용량으로 나눈 값 (규모 무관 비교 가능)
MAPE (%)평균 절대 백분율 오차낮을수록사용량 대비 오차 비율 (고객 규모 무관)
알림 F1알림 탐지 정밀도+재현율1에 가까울수록과다발생 알림의 정확도 (0~1)

비교 방법

같은 horizon_days와 contract_type끼리 비교합니다.

  • 제안 모델(lightgbm)이 모든 베이스라인보다 MAE/MAPE가 낮으면 성공
  • 검침일+10이 +20보다 오차가 크면 정상 (관측 기간이 짧으니까)
  • 알림 F1이 0.8 이상이면 실용적 수준

베이스라인 의미

모델방식
naive_last_month (전월 동일)이번 달 = 지난 달
seasonal_yoy (전년 동월)이번 달 = 작년 같은 달
moving_avg3 (3개월 이동평균)이번 달 = 최근 3개월 평균
partial_linear (부분 선형 보간)관측 기간 사용량을 전체 월로 선형 확장
partial_seasonal_yoy (부분 전년 동월)관측분 + 잔여분은 전년 비율로

2. Ablation 분석

export/perf_Ablation.csv

해석 방법

기본값(default) 대비 설정을 하나씩 바꿨을 때 MAPE가 어떻게 변하는지:

  • MAPE가 낮아지면 → 해당 설정 변경이 개선
  • MAPE가 높아지면 → 해당 설정 변경이 악화
  • 최적 조합(optimal_combined): 각 축에서 최선인 것을 합친 결과

설정 축 설명

축옵션의미
BTMscore / binary / exclude자가발전 고객 처리: 점수로 / 이진 플래그로 / 제외
기상v1_paper / v2_power / ...전국 대표기상 가중치: 인구수 / 전력판매량 / 균등 등
기준온도HDD base / CDD base냉난방도일 기준온도 (15/24 등)
피처선택True / False자동 피처 선택 적용 여부
export/perf_Ablation.csv 의 feature_group_contribution 부분

피처 그룹별 기여도 (제거 실험):

  • 기여도가 음수 = 제거하면 성능 악화 = 중요한 피처
  • 절대값이 클수록 해당 그룹이 예측에 기여하는 바가 큼

3. Sliding 상세 분석

월별 오차

export/sliding_error_by_month.csv

어떤 월이 예측하기 어려운지 확인. 여름(냉방)/겨울(난방) 전환기에 오차가 크면 기상 피처의 기여를 의미.

검침일별 오차

export/sliding_error_by_meter_day.csv

검침일에 따라 성능 차이가 있는지. 검침일이 1일(월초)일 때 vs 15일(월중)일 때 MAPE 차이를 비교.

계약종별 오차

export/sliding_error_by_contract.csv

일반용 vs 주택용 예측 난이도 비교. 일반용은 주말/평일 패턴이 뚜렷해 예측이 쉬울 수 있음.

검침일+10 vs +20

export/sliding_error_by_horizon.csv

+20일(관측 2/3)이 +10일(관측 1/3)보다 얼마나 정확한지. 차이가 크면 관측 기간 정보가 중요하다는 의미.

특수일 영향

export/sliding_error_by_special.csv

공휴일/연휴가 포함된 월이 예측하기 어려운지. disruption_ratio 피처의 유효성 확인.

최악/최선 조건

export/sliding_worst_dates.csv / sliding_best_dates.csv

오차가 가장 큰/작은 (연월, 검침일) 조합. 특정 시기에 모델이 실패하는 패턴을 찾는 데 활용.

4. SHAP 피처 중요도

export/shap/

이미지 해석

파일보는 법
shap_summary.png세로축: 피처 (위가 중요), 가로축: SHAP 값 (양수=예측 증가, 음수=감소), 점 색: 피처값 크기 (빨강=높음, 파랑=낮음)

correlation_heatmap.png피처 간 상관계수. 짙은 빨강/파랑 = 강한 상관 (다중공선성 주의)

수치 데이터

export/shap/shap_global.csv

피처별 평균 |SHAP| 값. 숫자가 클수록 모델에 미치는 영향이 큼.

5. 잔차 보정

export/perf_잔차_보정.csv + export/residual_correction.json

2-Stage Ridge 잔차 보정의 효과:

  • 보정 후 MAPE가 낮아졌으면 → 잔차 보정 채택
  • 높아졌으면 → 데이터 기간 부족으로 미채택 (보고서에 근거로 기술)

residual_correction.json의 pattern_analysis에서:

  • by_month: 월별 평균 잔차 → "7월에 모델이 과소 예측" 같은 패턴
  • by_horizon: +10일/+20일별 잔차 → horizon에 따른 체계적 편향
  • ridge_coefficients: 어떤 피처가 잔차를 설명하는지 (절대값 큰 순)
