## 【서식 1】데이터안심구역 이용신청서

### 프로젝트명
2026년도 AX 아이디어 경진대회 — 전기요금 과다발생 사전 예측모델 개발

### 이용목적
2026년도 AX 아이디어 경진대회 데이터 분석 부문 / 지정 분석(한국전력공사) 과제에
참가하기 위해, 한국전력공사가 제공하는 고객별 LP(Load Profile) 데이터를
데이터안심구역에서 분석하고자 합니다.

### 활용계획
고객별 15분 단위 LP 데이터(유효전력량, 무효전력량, 최대수요전력)를 학습하여
기준일(검침일) +10일, +20일 시점의 기준월 전력사용량을 예측하는 알고리즘을 개발합니다.
예측 결과를 바탕으로 전월 대비 +30%, 전년 동월 대비 +30%, 직전 3개월 평균 대비 +50%
초과 여부를 사전 알림하는 모델을 구축하여, 고객의 합리적인 전력 소비를 유도하고
효율적인 에너지 관리 및 운영 의사결정을 지원하고자 합니다.

### 전력데이터 필요 이유
- 과제에서 요구하는 예측 대상이 고객별 월 전력사용량이며, 이를 위해 개별 고객의
  시계열 사용 패턴 분석이 필수적입니다.
- 15분 단위 데이터를 통해 월 중간 시점(+10일, +20일)의 부분 관측량을 산출하고,
  잔여 기간을 예측하는 모델 구조를 적용합니다.
- 기상 데이터(HDD/CDD)와의 결합 분석을 통해 냉난방 수요 변동을 반영합니다.

### 요청 데이터
- 계약종별: 일반용 약 3,000호 + 주택용 약 500호
- 기간: 최대 3년간 (가용한 최대 범위)
- 단위: 15분 간격 LP 데이터
- 항목: 유효전력량(kWh), 무효전력량(kVarh), 최대수요전력(kW)
