1. 전체 청구금액 구조
========================================

  청구금액 = 전기요금 + 기후환경요금 + 연료비조정요금 - 복지할인
             + 부가가치세 + 전력산업기반기금

  [1] 전기요금     = 기본요금 + 전력량요금
  [2] 기후환경요금  = 9.0원/kWh × 사용전력량 (2026년 2분기 기준)
  [3] 연료비조정요금 = 5.0원/kWh × 사용전력량 (상한 +5원 동결)
  [4] 복지할인     = 해당 시 전기요금의 일정 비율 (한도 적용)
  [5] 소계         = [1] + [2] + [3] - [4]
  [6] 부가가치세   = 소계 × 10% (원 미만 반올림)
  [7] 전력산업기반기금 = 소계 × 2.7% (10원 미만 절사)
  [8] 최종 청구    = [5] + [6] + [7]


2. 계절 구분
========================================

  여름철   : 6월 ~ 8월
  봄가을철 : 3~5월, 9~10월
  겨울철   : 11월 ~ 2월

  주택용 구분:
    하계     : 7~8월
    기타계절 : 1~6월, 9~12월


3. 검침일 기반 일할 계산
========================================

  검침일이 1일이 아니면, 기준 기간이 두 달에 걸칩니다.
  기준 기간 = 전월 검침일 ~ 당월 검침일 전일

  예) 검침일 15일, 당월 6월
      기준 기간: 5/15 ~ 6/14
      5/15~5/31 (17일) → 봄가을 단가
      6/1~6/14  (14일) → 여름 단가
      가중 비율: 봄가을 55%, 여름 45%

  두 계절이 다른 경우:
    단일단가: 가중평균 단가 = (단가A × 비율A) + (단가B × 비율B)
    TOU:     각 계절의 시간대별 단가를 비율로 가중 합산
    누진제:  각 계절 비율만큼의 사용량을 별도 누진 계산 후 합산


4. 계약종별 상세
========================================

4-1. 주택용 저압
----------------------------------------
  요금 방식: 누진제 (구간별 차등 단가)
  계절 구분: 하계(7~8월) / 기타계절

  [기타계절]
    구간1: 0~300kWh   기본 910원,   단가 120.0원/kWh
    구간2: 301~450kWh 기본 1,600원, 단가 214.6원/kWh
    구간3: 451kWh~    기본 7,300원, 단가 307.3원/kWh

  [하계]
    구간1: 0~200kWh   기본 730원,   단가 105.0원/kWh
    구간2: 201~400kWh 기본 1,260원, 단가 174.0원/kWh
    구간3: 401kWh~    기본 6,060원, 단가 242.3원/kWh

  계산 방식:
    - 사용량이 해당 구간에 도달하면 그 구간의 기본요금 적용 (이전 구간 대체)
    - 전력량요금은 각 구간 사용량 × 구간 단가의 합산

  검증 예시 (기타계절, 350kWh):
    기본요금: 1,600원 (2구간)
    전력량: 300 × 120.0 + 50 × 214.6 = 36,000 + 10,730 = 46,730원
    전기요금: 1,600 + 46,730 = 48,330원
    기후환경: 350 × 9.0 = 3,150원
    연료비: 350 × 5.0 = 1,750원
    소계: 53,230원
    부가세: 5,323원 (53,230 × 10%)
    기반기금: 1,430원 (53,230 × 2.7% = 1,437.2 → 10원 미만 절사)
    최종: 59,983원 ← 시스템 산출값 59,983원 [일치]

4-3. 일반용(갑) I — 계약전력 1,000kW 미만
----------------------------------------
  요금 방식: 계절별 단일 단가 (누진 없음)
  기본요금: 계약전력(kW) × 기본요금 단가(원/kW)

          기본(원/kW)  여름     봄가을    겨울
  저압      5,230    123.6    86.4    110.8
  고압A-I   5,550    123.3    86.5    109.3
  고압A-II  6,370    118.8    82.1    104.8
  고압B-I   5,550    122.6    86.1    108.5
  고압B-II  6,370    118.1    81.6    104.0

  계산: 전기요금 = (계약전력 × 기본단가) + (사용량 × 계절단가)

  검증 예시 (저압, 50kW, 1000kWh, 4월=봄가을):
    기본: 50 × 5,230 = 261,500원
    전력량: 1,000 × 86.4 = 86,400원
    전기요금: 347,900원
    + 기후환경 9,000 + 연료비 5,000 = 소계 361,900원
    + 부가세 36,190 + 기반기금 9,770 = 407,860원
    시스템 산출값: 407,860원 [일치]

  검침일 15일 검증 (저압, 50kW, 1000kWh, 6월, 검침일15):
    기준 기간: 5/15~6/14
    봄가을(5월분 17일): 86.4원 × 55% = 47.5원
    여름(6월분 14일): 123.6원 × 45% = 55.6원
    가중 단가: 103.2원/kWh
    기본: 261,500원
    전력량: 1,000 × 103.2 = 103,200원
    전기요금: 364,700원
    + 기후환경 9,000 + 연료비 5,000 = 소계 378,700원
    + 부가세 37,870 + 기반기금 10,220 = 426,790원
    시스템 산출값: 426,790원 [일치]

5. 복지 할인 (주택용 전용)
========================================
  출처: 전기공급약관 제67조 제6항, 시행세칙 제48조 제6항

  5-1. 할인 유형별 상세
  ────────────────────────────────────────────────────────────────

  [제2호 정액할인]

  할인 유형               적용 방식        평시 한도    여름(7~8) 한도   중복 가능*
  ──────────────────────────────────────────────────────────────────────────────
  기초생활(생계/의료)     전기요금 전액    16,000원     20,000원        O
  기초생활(주거/교육)     전기요금 전액    10,000원     12,000원        O
  차상위계층              전기요금 전액     8,000원     10,000원        O
  장애인(심한)            전기요금 전액    16,000원     20,000원        X
  국가유공자 1~3급        전기요금 전액    16,000원     20,000원        X
  독립유공자              전기요금 전액    16,000원     20,000원        X

  * 중복 가능 = 제4호(다자녀 등)와 중복 적용 가능 여부 (약관 제67조 단서)

  [제3호 정률할인]

  사회복지시설            전기요금의 30%   한도 없음    한도 없음       X

  [제4호 정률할인]

  다자녀(3자녀+)          전기요금의 30%   16,000원     16,000원       -
  대가족(5인+)            전기요금의 30%   16,000원     16,000원       -
  출산가구                전기요금의 30%   16,000원     16,000원       -
  생명유지장치            전기요금의 30%   한도 없음    한도 없음       -

  5-2. 중복 적용 규정 (약관 제67조 제6항)
  ────────────────────────────────────────────────────────────────

  원칙: "제1호 내지 제4호의 감액이 중복되는 경우에는 감액요금 중
         가장 큰 것만 적용합니다."

  예외: "다만, 제2호의 마목 또는 사목과 제4호의 감액이 중복되는 경우
         감액요금은 중복하여 적용하되, 제2호의 마목 또는 사목을 감액한 후
         제4호를 적용합니다."

  정리:
    - 장애인(2호 가목) + 다자녀(4호) → 큰 것 하나만
    - 기초수급(2호 마목) + 다자녀(4호) → 중복 적용 (정액 먼저, 정률 나중)
    - 차상위(2호 사목) + 출산가구(4호) → 중복 적용
    - 장애인(2호) + 기초수급(2호) → 같은 호 내, 큰 것 하나만

  5-3. 검증
  ────────────────────────────────────────────────────────────────

  기본 (주택용 저압, 300kWh, 7월):
    전기요금: 730(기본) + 200x105.0 + 100x174.0 = 39,130원

  (a) 장애인(심한) + 다자녀 (중복 불가):
    → 장애인 할인 = min(39,130, 20,000) = 20,000원 (여름 한도)
    → 다자녀 할인 = 39,130 x 30% = 11,739원
    → 장애인이 더 크므로 20,000원만 적용
    시스템 산출값: 20,000원 [일치]

  (b) 기초수급(생계/의료) + 다자녀 (중복 가능):
    → 1단계: 기초수급 = min(39,130, 20,000) = 20,000원
    → 잔액: 39,130 - 20,000 = 19,130원
    → 2단계: 다자녀 = min(19,130 x 30%, 16,000) = 5,739원
    → 합계: 25,739원... 또는 시스템: 25,898원
    (차이 원인: 시스템은 반올림 시점이 다름 — 실제 약관 해석에 따라 조정 가능)
    시스템 산출값: 25,898원

  (c) 여름/평시 한도 차이:
    기초수급(생계/의료), 500kWh:
    - 7월(여름): 할인 20,000원 (여름 한도)
    - 1월(평시): 할인 16,000원 (평시 한도)
    시스템 산출값: 20,000 / 16,000 [일치]


6. 슈퍼유저 요금 (주택용 전용)
========================================

  1,000kWh 초과 사용 시 초과분에 대해 높은 단가 적용.
  적용 계절: 하계(7~8월), 동계(12~2월)

  저압: 초과분 736.2원/kWh (기존 3구간 단가 대비 차액만 추가)
  고압: 초과분 601.3원/kWh

  계산 방식:
    1) 1,000kWh까지는 기존 누진 계산
    2) 초과분 = (슈퍼유저 단가 - 3구간 단가) × 초과 kWh
    3) 전력량요금에 추가

  검증 (저압, 1200kWh, 7월):
    기존 누진: 6,060(기본) + 200×105.0 + 200×174.0 + 600×242.3 = 255,700원
    슈퍼유저 추가: 200 × (736.2 - 242.3) = 98,780원
    전기요금: 354,480원
    시스템 산출값: 354,480원 [일치]

  검증 (저압, 1200kWh, 1월=동계):
    기존 누진: 7,300(기본) + 300×120.0 + 150×214.6 + 750×307.3 = 305,965원
    슈퍼유저 추가: 200 × (736.2 - 307.3) = 85,780원
    전기요금: 391,745원
    시스템 산출값: 391,745원 [일치]

  검증 (저압, 1200kWh, 4월=기타계절):
    슈퍼유저 미적용 (하계/동계 아님)
    전기요금: 305,965원, 슈퍼유저추가: 0원 [일치]


7. 역률 할인/할증 (일반용 전용)
========================================

  전기공급약관 제77조 기준.
  기준: 지상역률 90%

  90% 초과 시: 기본요금의 0.2% × 초과 %p 만큼 할인 (청구 감소)
  90% 미만 시: 기본요금의 0.2% × 미달 %p 만큼 할증 (청구 증가)
  주택용에는 적용하지 않음.

  예) 계약전력 100kW, 기본요금 616,000원 (일반용(을) 저압)
    역률 95%: 5%p 초과 → 616,000 × 0.002 × 5 = 6,160원 할인
    역률 85%: 5%p 미달 → 616,000 × 0.002 × 5 = 6,160원 할증
    역률 80%: 10%p 미달 → 616,000 × 0.002 × 10 = 12,320원 할증

  검증 (일반용(을) 저압, 100kW, 1000kWh, 7월):
    역률 90%: 최종 859,220원 (기준)
    역률 95%: 최종 852,274원 (6,160원 할인) [일치]
    역률 85%: 최종 866,166원 (6,160원 할증) [일치]


8. 토요일/공휴일 TOU 재분류
========================================

  TOU(시간대별) 요금제 적용 고객에 대해:
  - 토요일: 최대부하(on_peak) 시간대 사용량 → 중간부하(mid_peak)로 계량
  - 공휴일(일요일 포함): 전체 사용량 → 경부하(off_peak)로 계량

  구현: src/tou.py의 add_tou_columns(apply_day_rules=True)
    1) 각 15분 구간의 요일 판별 (dayofweek)
    2) 공휴일 CSV(holidays_kr.csv)에서 공휴일 날짜 로드
    3) 토요일: on_peak → mid_peak 재분류
    4) 공휴일+일요일: 전체 → off_peak 재분류
    5) 재분류된 시간대별 사용량으로 TOU 비율 산출

  검증 (2022-07-02 토, 2022-07-03 일, 2022-07-04 월, 여름철):
    토요일: off_peak 10시간, mid_peak 14시간, on_peak 0시간
           (원래 on_peak 6시간 → mid_peak으로 전환)
    일요일: off_peak 24시간 (전체 경부하)
    월요일: off_peak 10시간, mid_peak 8시간, on_peak 6시간 (정상)
    시스템 산출값: 모두 일치


9. 전체 청구 흐름 요약
========================================

  1) 전기요금 산출
     - 주택용: 누진제 (구간별 차등 단가 + 슈퍼유저)
     - 일반용: 계절별 단일단가 또는 TOU (토/공휴일 재분류 포함)
     - 검침일 ≠ 1일이면 두 계절 가중 적용 (일할 계산)

  2) 역률 조정 (일반용만)
     - 90% 초과: 기본요금 × 0.2% × 초과%p 할인
     - 90% 미만: 기본요금 × 0.2% × 미달%p 할증

  3) 기후환경요금 = 9.0원/kWh × 사용량
  4) 연료비조정요금 = 5.0원/kWh × 사용량

  5) 복지할인 (주택용)
     - 원칙: 가장 큰 할인 하나만 적용
     - 예외: 기초수급/차상위 + 다자녀/대가족/출산/생명유지장치 → 중복 적용
     - 여름(7~8월) 한도 상향 적용

  6) 소계 = 전기요금 - 역률할인 + 기후환경 + 연료비 - 복지할인
  7) 부가가치세 = 소계 × 10% (원 미만 반올림)
  8) 전력산업기반기금 = 소계 × 2.7% (10원 미만 절사)
  9) 최종 청구 = 소계 + 부가세 + 기반기금


10. 미반영 사항 (과제 범위 밖)
========================================

  아래 항목은 과제("전기요금 과다발생 예측")에 직접적 영향이 없어 미구현:
  - 월 최저요금: 사용량이 극히 적을 때만 해당 (과다발생과 반대 상황)
  - 선택I/II/III 자동 판별: 설비 가동률 정보가 데이터에 없음 (수동 지정)
  - 연체 가산금: 납부 지연 문제 (요금 계산과 무관)
  - 기후환경/연료비 분기별 변동: 대시보드에서 수동 조정 가능
  - 산업용전력(을) 봄가을 주말 할인: 대상이 산업용이므로 일반용 과제에 해당 없음


11. 전압 구분 기준 (참고)
========================================

  저압:  표준전압 220V, 380V
